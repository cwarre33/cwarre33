### What I ship

- **Contact-center automation:** custom Zendesk round robin with dedicated-agent routing; **4,000+ tickets** auto-assigned in production
- **Inventory platform + CI/CD:** Next.js + shared Postgres RDS (~5GB / ~23 yrs, ~15-min sync); browse ~11s to ~500ms; staging to prod pipeline on **ECS/Fargate** (Terraform/SSM, Entra SSO)
- **Conversational AI:** SellSmart + Digital-to-Store agents on **Microsoft Copilot Studio**, grounded in NetSuite
- **SofaScope:** CLIP + FAISS visual search for the world's largest furniture store ([live](https://sofascope.furniturelandsouth.com)); latency **15s to &lt;500ms**
